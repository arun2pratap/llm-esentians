# LLM Essentials

A hands-on Python learning playground for exploring **Large Language Models (LLMs)**.

The project contains small implementations and experiments focused on understanding LLM concepts through code.

## Current Topics

* Tokenization
* Token IDs
* Token embeddings
* LLM inference fundamentals

## Structure

```text
llm-esentians/
├── .venv/
├── src/
│   └── llm_essentials/
│       └── inference/
│           ├── tokenization.py
│           └── embeddings.py
├── README.md
└── .gitignore
```

## Setup

```bash
source .venv/bin/activate
```

Run an example:

```bash
python src/llm_essentials/inference/tokenization.py
```

More topics and experiments will be added as the project evolves.
